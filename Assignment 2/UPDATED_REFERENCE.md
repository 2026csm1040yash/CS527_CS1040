# CS527 Lab 2 – Updated Reference Version

This project follows the supplied reference screenshot for the worked array-sum example.

## Important correction

For constant data movement:

    x1 = 0

The supplied reference image shows:

    F 1 0 0

Therefore the compiler emits opcode `0x0F` for constant-to-register movement and prints bytecode in uppercase hexadecimal.

The compiler does not append a synthetic HALT instruction. Instruction memory is initialized to zero, so opcode 0 at the first unused instruction terminates execution. This matches the supplied reference image, which contains exactly 12 bytecode instructions.

## Verified example

Input:

    x1 = 0
    x2 = 0
    x3 = 0
    x4 = [x3]
    .loopback
    x15 = x1 - x4
    BEQ .exit
    x3 = x3 + 4
    x6 = [x3]
    x2 = x2 + x6
    x1 = x1 + 1
    BAL .loopback
    .exit
    [x3] = x2

Generated bytecode:

    F 1 0 0
    F 2 0 0
    F 3 0 0
    5 4 0 3
    2 F 1 4
    10 0 0 6
    9 3 3 4
    5 6 0 3
    1 2 2 6
    9 1 1 1
    1E 0 0 FA
    6 3 0 2
